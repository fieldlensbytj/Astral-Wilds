# Monster roster

Ten original monster designs in a cohesive, polished, stylized 3D game-art aesthetic, drawing broad inspiration from Kardmi, Pokémon, Palworld, and Digimon. The set contains ten individual **1254 × 1254 PNG images**, generated with the built-in image-generation tool. These are 3D-style rendered concept images.

The complete prompt set is saved in `generation-prompts.md`.
